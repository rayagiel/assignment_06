I learned how to call APIs and about the HTTP status codes. In the module apicalls.py, 
I was able to write several functions, including classify_mentions() and get_sentiment(). 
I used my API key from the IoT Cent portal and I stored it in the .env
file. It is not in any of the modules in the package; it is in .gitignore so Git 
does not track it and it never gets pushed to GitHub, so others cannot steal it. I also learned about HTTP status codes. I learned that response.raise_for_status() will only 
raise an exception if the status code is in the 400s or 500s. A status code in the 400s means 
a client error and a status code in the 500s means a server error. A staus code in the 200s means the request 
was successful. I also learned about caching. Once I called the API, the response is saved and that 
response is reused if the same request is made. For example, in the function subject_steps(), 
it checks to see if the cache file exists with "if os.path.exists(cache_file)". If it does, 
it just returns the saved result instead of making a new request.
