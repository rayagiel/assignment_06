I learned how to call APIs and about the HTTP status code. In the module apicalls.py, 
I was able to write several functions, including classify_mentions() and get_sentiment(). 
I used my API key from the IoT Cent portal and I kept it hidden in the .env
file so users cannot steal it.  I also learned about HTTP status codes and 
that response.raise_for_status() will only raise an exception if there is an issue. A code in the 400s, which means 
a client error, or a code in the 500s, which means a server error, will raise an exemption. A code in the 200s means the request was successful. I also learned about caching. 
Once I called the API, the response is saved and that response is reused if the same request was made. For example, in the function subject_steps(), 
it checks to see if the cache_file path exists with "if os.path.exists(cache_file)". If it does, 
it just return the existing response to that request instead of making a new request.
